像搭积木一样组合匹配条件与 Action，实时生成可复制的新 Rewrite 语法。

rewrite.confhttp-request
http-request if ${url} ~= /^https:\/\/api[.]example[.]com/ && ${request.method} == "POST" then request.header.set(name="X-Loon", value="true") | request.header.delete(name="Cookie")
