# 节点筛选

节点筛选用于从本地节点和订阅节点中快速建立分类，例如筛选香港节点或手动组成一个节点组。

## 支持的筛选方式

- `NodeSelect`：手动选择节点。
- `NameKeyword`：按节点名称中的关键词筛选。
- `NameRegex`：使用正则表达式筛选节点名称。

## 配置方法

进入 App 的配置页面，选择“筛选节点”，然后点击右上角添加。默认筛选全部节点，可按需调整。

## 常用正则

```text
^.*(A|B)      包含 A 或 B
(A.*B|B.*A)  同时包含 A 和 B
^(?!.*A)     不包含 A
^(?!.*?B).*A 包含 A，但不包含 B
```
