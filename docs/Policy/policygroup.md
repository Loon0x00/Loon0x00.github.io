# 策略组

策略组由节点或其他策略组组成，可以手动或自动选择其中的策略。策略组在 `[Proxy Group]` 中声明，并支持嵌套。

## select 策略组

手动选择要使用的策略。

## url-test 策略组

定期测试所有节点，并选择延迟最低的节点。

| 参数 | 说明 |
|---|---|
| `url` | 测速 URL，Loon 会发送 Header 请求 |
| `interval` | 测速间隔，单位为秒 |
| `tolerance` | 新旧最优节点的延迟差小于该值时不切换，单位为毫秒 |

## fallback 策略组

定期测试节点，并选择列表中第一个可用节点。

| 参数 | 说明 |
|---|---|
| `url` | 测速 URL |
| `interval` | 测速间隔，单位为秒 |
| `max-timeout` | 超过该时间的节点视为不可用，单位为毫秒 |

## load-balance 策略组

按照指定算法在子策略之间分配请求。

| 参数 | 说明 |
|---|---|
| `url` | 测速 URL |
| `interval` | 测速间隔，单位为秒 |
| `max-timeout` | 超过该时间的节点视为不可用，单位为毫秒 |
| `algorithm` | 负载均衡算法 |

支持的算法：

- `Random`：随机选择。
- `PCC`：相同主机名固定使用同一节点。
- `Round-Robin`：按顺序轮询。
