0.4.0 alpha

2026 年 8 月 20 日
Build 69
  • 优化首次启动引导及 System Extension 安装、授权与更新流程
  • 重构 VPN 管理，提升连接、断开和配置管理的稳定性
  • 升级菜单栏，支持仅图标、仅网速及组合显示，并可控制进程信息展示
  • 重做节点添加与编辑页面，补全多种协议配置项
  • 修复首页、策略组及其他界面的交互和显示问题
  • 修复显示主应用无法切到前台的问题

0.4.0 alpha

2026 年 8 月 18 日
Build 66
  • 全新的 UI
  • 整个 App 使用 AppKit 完全重新实现，丢弃原来的 SwiftUI
  • 侧边栏支持展开收起
  • 状态栏面板鼠标放在菜单上会自动出现子面板
  • 重构整个引导流程，激活、安装帮助工具更加方便安全
  • 重构 XPC 进程交互模块，主 App 和 NE 内核交互更加安全便捷
  • 调整进程统计数据逻辑，更加精准高效
  • 优化节点、策略组测速逻辑，减少节点过多导致的 UI 卡顿和 CPU 占用率高的问题
  • 增加状态栏配置，可以自行设置显示内容和显示策略组的数量
  • 增加 UI 主题，可以自行设置或者导入他人主题
  • 优化插件详情页的 UI 设计
  • 目前主要重新设计了一、二级展示内容的 UI，编辑配置的 UI 后续会继续完善
