Script 配置编辑器

选择脚本类型并填写配置，右侧会实时生成可复制的新语法。

查看语法文档 →转换旧版配置 →仅在浏览器本地生成，不会上传配置

配置 HTTP Script 的 URL、Method、Header 或插件参数条件。

Script URL 正则仅用于匹配，不支持 as 捕获变量；需要捕获内容时可在 JavaScript 中读取 Request/Response 数据并再次执行正则。
